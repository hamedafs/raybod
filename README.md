# رایبد | Investor Profiler

پرسشنامهٔ فارسی برای ثبت نام مشتری، ارزیابی سه‌سطحی ریسک، تعیین تیپ سرمایه‌گذار، گزارش متنی هوش مصنوعی و بک‌آفیس.

## اجرای محلی
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn main:app --reload --port 8000
```
سپس `http://127.0.0.1:8000` را باز کنید. بک‌آفیس: `http://127.0.0.1:8000/admin`

## هوش مصنوعی رایگان
برای شروع می‌توانید از OpenRouter استفاده کنید: `LLM_API_KEY` را تنظیم کنید، `LLM_BASE_URL=https://openrouter.ai/api/v1` و `LLM_MODEL` را روی شناسهٔ مدل رایگانِ موجود در حساب خود بگذارید. گزینهٔ جایگزین، Google AI Studio است: `GEMINI_API_KEY` را وارد کنید؛ در این حالت تنظیمات `GEMINI_BASE_URL` و `GEMINI_MODEL` استفاده می‌شوند. کلید را در کد، مخزن یا فرانت‌اند نگذارید. در پنل مدیر می‌توان endpoint تشخیصی `/api/ai-test` را برای آزمایش اتصال فراخوانی کرد؛ این endpoint به احراز هویت مدیر نیاز دارد. سهمیهٔ رایگان و مدل‌های در دسترس ممکن است تغییر کنند. در پلن رایگان ممکن است داده‌های ارسال‌شده برای بهبود محصولات استفاده شوند؛ پیش از استفاده با اطلاعات واقعی مشتریان، شرایط داده و مجوزهای شرکت را بررسی کنید. نام مشتری عمداً در درخواست AI فرستاده نمی‌شود، اما پاسخ‌های متنی و داده‌های ارزیابی برای تولید گزارش ارسال می‌شوند. بدون کلید هم پرسشنامه و امتیازدهی کار می‌کند؛ گزارش با متن جایگزین تولید می‌شود.

## دیتابیس
- محلی: SQLite در `data/rayebod.db`.
- ابری: متغیر `DATABASE_URL` را به PostgreSQL پروژهٔ Supabase وصل کنید؛ SQLAlchemy جدول را خودکار می‌سازد.
- حتماً `ADMIN_PASSWORD` و `SESSION_SECRET` را پیش از انتشار تغییر دهید.

راهنمای استقرار رایگان در `DEPLOY.md` است. این ابزار کمکی برای شناخت مشتری است و جایگزین اعتبارسنجی رسمی مدل ریسک یا بررسی کارشناس نیست.
